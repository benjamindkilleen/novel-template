# Characters

One page per character — who they are, what they want, and how they change. The
pages in this section are listed in the sidebar; lead with protagonists, then
supporting cast, then minor names (tag them so the [Tags](../tags.md) page can
group them).

!!! tip "Add a character"
    Create a new Markdown file in `docs/characters/` (e.g. `coren.md`) — it
    appears in the nav automatically, no config to edit. Link to it from anywhere
    with a wikilink by filename, e.g. `[[maren]]`.

??? note "Copy this template for a new character"
    ```markdown
    ---
    title: Name
    tags: [character]
    ---

    # Name

    !!! abstract "At a glance"
        - **Role:**
        - **Age / appearance:**
        - **First appears:**

    **Want (external goal):**

    **Need (internal arc):**

    **Flaw / wound:**

    **Voice / mannerisms:**

    **Relationships:**

    **Secrets:**

    **Arc summary:**
    ```
