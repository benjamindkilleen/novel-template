# Tags

Every topic page can carry `tags:` in its front matter. They're collected here so
you can browse the bible by kind — all characters, all locations, everything
tagged `magic`, and so on — alongside the full-text search box at the top.

To tag a page, add to its front matter:

```yaml
---
title: Maren
tags: [character, protagonist]
---
```
